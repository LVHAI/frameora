# Frameora Website

A lightweight static website for GitHub Pages with separate URLs for:

- Marketing: `/`
- Support: `/support.html`
- Privacy Policy: `/privacy.html`
- Terms of Use: `/terms.html`

## Publish with GitHub Pages

1. Create a GitHub repository, for example `frameora-website`.
2. Upload all files and folders in this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

Your URLs will look like:

- `https://YOUR-GITHUB-USERNAME.github.io/frameora-website/`
- `https://YOUR-GITHUB-USERNAME.github.io/frameora-website/support.html`
- `https://YOUR-GITHUB-USERNAME.github.io/frameora-website/privacy.html`
- `https://YOUR-GITHUB-USERNAME.github.io/frameora-website/terms.html`

If you use a custom domain, replace the URLs with that domain.

## Before publishing

- In `support.html`, replace `[YOUR SUPPORT EMAIL ADDRESS]` with an email address you monitor.
- In `terms.html`, replace `[YOUR SUPPORT EMAIL ADDRESS]` and review the legal template.
- In `index.html`, replace the `#` on the App Store button with the real App Store URL when available.
- In `privacy.html`, replace the placeholder with a complete policy that accurately describes the released app. Do not submit the placeholder as the final privacy policy.
- Verify all links after GitHub Pages is live.

All pages are in English. The Privacy Policy navigation link is already present in the header and footer on every page.
